# FotoAra

Galerindeki fotoğrafları **internetsiz, telefonda** arar. Hiçbir fotoğraf dışarı çıkmaz.

**Durum:** 0.1, altyapı. Şu an sadece renk arar ("mavi", "kırmızı"...).
Sıradaki adım: çok dilli CLIP modeliyle "denizde kırmızı şemsiyeli fotoğrafım" gibi cümlelerle arama.

## Derleme
GitHub Actions ile otomatik. Secrets: `KEYSTORE_B64`, `KEYSTORE_PASSWORD`.
